# Pocket Ledger

移动优先、可安装、离线可用的本地记账 PWA。

- 收入 / 支出
- 分类、日期、备注
- 月度收入、支出、结余
- 搜索与删除
- 深色模式
- 数据保存在浏览器 localStorage，不上传服务器
- 可安装到 Android 主屏幕
- 首次加载后支持离线使用

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```
